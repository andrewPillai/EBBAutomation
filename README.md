# EBB Automation Layer

Build spec and Kimi Code handoff for a multi-tenant SaaS that submits, verifies, and receipts US natural gas pipeline nominations on behalf of shippers (NAESB EDI/EDM + EBB portal/flat-file automation), with receipts, escalation, kill switches, shadow mode, and storm mode.

**Start here:** [`ebb_automation_spec_v1.2.md`](ebb_automation_spec_v1.2.md) — the frozen build spec (v1.2). It is self-contained: 7 ADRs, 65 requirements with acceptance criteria, the agent build pipeline, the non-code critical path, the risk register, glossary, and sources. Changes only via ADR amendment with contract tests in the same PR.
